# 指定名次与榜单范围

状态：completed（本地实施与验收完成，公共发布不在本次范围）。
类型：baseline；实施与验证日期：2026-11-16。

## 契约

- 显式名次和区间起点不受客户端展示范围、个人定位或分数扫描上限约束。
- 原始区间保留，数量预算限制执行区间；倒序、零及超协议整数范围明确拒绝。
- 官方榜直接定位协议页；过滤榜先读取排除前缀，再映射显示名次。
- 手工区间缓存同样使用显示名次映射，不再把过滤后的起点直接当服务器偏移。
- 过滤前缀固定 1000 条是既有排除规则，不是榜单名次上限。失败不冒用原始名次。
- 定位、分数搜索、刷新范围仍受各自配置预算约束，不新增配置。
- 网络榜使用uint32偏移边界；本地样本只受SQLite有符号整数边界约束，不套网络边界。

1-3、1000-1002、1001、1001-1100、1901-2000、2001-2100、9901-10000、19901-20000

其他协议没有从这次苏摩结果推断最大名次；没有发现第二处客户端范围硬截断。

同日补充只读实测4481：图鉴积分156/1、群星牌240/1、北冥试炼267/1，

不将这些边界观察推广为所有榜单有相同总长度；没有请求生产游戏账号或发送聊天。

扫描范围不超过1000的未命中仍是可信的有界记录，继续保留。
保留前1000可信页、正向事实、历史锚点及其他榜缓存，不修改采集时间。
