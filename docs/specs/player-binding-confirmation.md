# 本人绑定确认与查询展示

Status: completed (2026-11-20).
Contract: baseline extension; existing cooldown, quota and storage schema retained.

## Behavior

- 本人首次绑定、换绑和查询中的建议均先说明目标、当前绑定及实际冷却，再确认。
- 显式绑定选否直接结束；查询建议选否继续原查询；0/超时不写绑定。
- 所有本人绑定入口共用确认模板；成功先单独发送默认米米号及实际冷却期限，
  再发送资料或原快捷结果。同号不重复回执、不重写、不重置冷却。失败不得隐藏。
- 快捷绑定成功后查询失败明确说明绑定已生效，不回滚、不自动重复执行。
- 超管代绑保留权限、豁免及管理回执；不修改生产或业务数据，不增加配置。

## Shared Contract

绑定写入以结构化结果区分成功、实际修改和错误文案，不改写待展示资料正文。
成功回执不承担原查询计费或菜单锚点回调，发送失败仍继续查询且不回滚绑定。
公共确认按平台、机器人、会话及操作者隔离，提交前复查功能、目标和绑定状态。
SQLite原事务校验预期状态，不新增迁移；冷却说明与拒绝规则共用北京时间计算。
显式绑定复用已验证资料及成功回执计费规则，不为确认重复联网或扣额。
