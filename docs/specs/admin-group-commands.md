## Behavior

仅提供 `[bot] admin_commands_in_groups = true`，默认允许超管在群聊使用管理口令。
设为false仅关闭群聊管理入口；超管私聊保持可用。不提供both/group/private选项。
普通查询、群管理员功能、个人TD、AI私聊和超管专属资料查询不受影响。
