# 私有扩展安装失败保护

Status: `verified`

Contract: `target`

Owner: `app.private_extensions`

Related architecture: [ARCHITECTURE.md](../../ARCHITECTURE.md)

## Problem

`28c0d64c` 的 `shutil.move` 回退可能把目录逐文件复制到 `current`。复制中断时，
不完整的 `current` 会阻止回滚，原实现的 `finally` 仍会删除 `.previous-*`。
即使只用重命名，恢复旧包失败时也不能删除最后一份有效包。现有正常安装测试未覆盖这些失败路径。

## Design

- 安装只在启动前串行执行，校验完成后切换目录。
- 同一文件系统中只重命名目录，不用复制回退产生可被加载的半包。
- 对 `PermissionError` 做有限重试；失败仍明确向上传递，不把权限错误伪装为成功。
- 只有新包成功安装后才清理旧包。切换失败则恢复旧包；恢复也失败时保留备份，并在异常中给出恢复路径。
- 不新增运行依赖、配置、旧包读取路径或部署迁移。

## Acceptance

- [x] 正常首次安装及升级保持可用。
- [x] 新包切换失败后恢复旧包。
- [x] 旧包移出失败时旧包保持原位。
- [x] 恢复失败保留有效备份并明确报告路径。
- [x] 首次安装失败没有半包 `current`。
- [x] 暂时权限错误可有限重试；永久失败不会复制回退。
- [x] Ruff、类型检查及安装/启动回归通过。

## Evidence

2026-09-05：安装及启动 preflight 测试 26 passed；针对生产模块的 BasedPyright
为 0 errors，Ruff 通过。新增测试注入首次安装、移出旧包、激活新包和恢复旧包的
文件系统失败；永久锁不会复制出半包，恢复失败会保留并报告有效备份路径。

本项只保证进程内安装失败的可恢复性，不声称两个目录重命名是跨进程崩溃事务；
掉电后的自动恢复和多进程同时安装不在本项验收内。不代表多平台私有扩展发布已完成。
