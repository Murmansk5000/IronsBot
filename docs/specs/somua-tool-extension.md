# 苏摩工具扩展交付

状态：实现、隔离功能、生产迁移 A 与真实普通更新 A→B 验收完成；临时保护源码已退役。
部署与运维验收以对应 SHA 的工作流和独立验收报告为准。

## 目标

公共镜像保持普通更新入口。私有制品提供扩展代码和独立的苏摩工具根目录，
非商业转换器不进入公共镜像。仍只有一个机器人容器，不在启动时安装系统软件。
同一兼容契约的公共代码升级不要求修改或重建 private。

## 契约与所有权

公共扩展接口、Python ABI、Linux 架构和 libc 能力作为兼容检查依据；
公共提交 SHA 仅记录构建及验证来源，不能替代接口兼容判断。
代码包保持小体积限制，工具目录从同一个不可变镜像 ID 流式读取，分别限制
下载、展开字节数及条目数。清单记录工具指纹、文件哈希、大小、权限和许可。

代码与工具只有在兼容、完整性和隔离探针通过后才激活。工具版本目录不可变，
正在运行的任务不迁移路径。安装失败保留旧的完整兼容制品；没有可用工具时，
苏摩图片关闭，中文详情与导航保留。取消必须等待正在写入的工作结束再清理。

旧固定私有镜像的临时更新保护已从源码退役。公共镜像按普通更新路径运行；
私有工具仍通过独立制品、兼容清单与隔离探针安装和复用。
迁移及真实普通 A 到 B 更新的证据独立记录。

## 验收

覆盖代码与工具来源一致、流式上限、安全提取、损坏清单、探针失败、原子切换、
并发安装、取消、兼容公共升级，以及两平台文字和图片保底。
非生产 Linux 验证默认安全边界、真实 WebGL2 和既有正确样图；不使用本机 WSL。
实际检查结果在完成后补充，不把计划记为已通过。
