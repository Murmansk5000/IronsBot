# 指令分类、重复限制与菜单

`messaging.command_cooldown.duplicate_window_seconds` 分别配置 `taomee`、
`local`、`other_network`，默认秒数为 `120 / 0 / 120`。0 只关闭成功完成后的
同请求重复限制，执行中的操作仍保留占用。失败或取消不会产生新的成功记录。
这与 `enabled` 控制的滑动窗口限频、玩家额度及超级管理员豁免分别管理。

## 动作分类清单

| 类别 | 动作 |
| --- | --- |
| taomee | 玩家基础资料、收集、巅峰、群星牌排名、神兽榜、玩家所属战队、战队资源查询、官方榜单及刷新、幸运橱窗查询、私有阵容 |
| local | 帮助、TD/订阅设置、绑定与身份设置、榜单显示设置和状态、本地样本榜、本地精灵/技能/刻印/装备/群星牌资料、新增内容、固定回复、图片配置、重启 |
| other_network | B站动态及刷新、AI、活动查询、开服联网检查、数据库同步、镜像检查与更新 |

分类由公共语义动作登记，不随缓存命中或渲染素材下载改变。
`core/action_categories.py` 保存内置动作与旧入口名称的分类清单；公共命令目录
启动时检查遗漏。新扩展可在 `ActionDefinition(..., category=RequestCategory.TAOMEE)`
及对应的 `CommandContract` 显式声明分类，不需修改公共仓库的内置清单。
私有阵容的现有动作与命令 ID 已登记，可继续加载。

重复身份由实际操作者、机器人、会话、语义动作和真实目标共同组成。
玩家别名先解析成米米号，直接查询与菜单查询复用同一动作。
旧的单值 `duplicate_window_seconds = 60` 仍可读取，映射为两类联网查询
60 秒、本地 0 秒，不影响菜单。

## 菜单与事件

公共菜单独立使用 120 秒：成功发送后计时，有效选择刷新等待期。
新根菜单替换旧菜单；返回上级恢复页面快照并重新计时，不重新执行其查询。
无效输入或被拒绝的重复请求不续期。已接受的后台查询不因菜单等待到期被取消，
但重新发起命令或退出后，旧任务不得重新打开旧菜单。

其他成员只能引用当前菜单执行已授权的非退出选项；其权限、额度及重复记录
归实际操作者，第三者输入 0 不会关闭发起人的菜单。

消息上报重放与用户重复输入无关。OneBot 按机器人、会话和消息 ID 保留有界的
24 小时进程内记录；QQ 官方沿用持久事件记录并增加会话隔离，迁移保留旧记录。
重复事件静默忽略。新消息 ID 即使文本相同，也会正常进入业务策略。
